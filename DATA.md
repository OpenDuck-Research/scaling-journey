# sources

This section contains only sources that support the framework’s claims. It is intentionally conservative.

## Linus’s Law

- Quote: “Given enough eyeballs, all bugs are shallow.”
- Origin: Eric S. Raymond, The Cathedral and the Bazaar
- Reference: Wikipedia entry on Linus’s Law
- Link: https://en.wikipedia.org/wiki/Linus%27s_law

This idea is important, but it is also often overstated. The framework treats it as a hypothesis, not as a complete security law.

## Heartbleed

- Vulnerability: CVE-2014-0160
- Discovered: 2014
- Impact: critical
- Public code: yes
- Notable fact: the issue remained undetected for a long period despite public visibility
- Source: Mend.io analysis on Linus’s Law and Heartbleed
- Link: https://www.mend.io/blog/are-all-bugs-shallow-questioning-linus-s-law/

Additional reporting:
- CNBC coverage of Heartbleed
- Link: https://www.cnbc.com/2014/04/10/heartbleed-bug-is-changing-your-password-enough.html

This is the clearest counterexample to the idea that visibility alone guarantees security.

## Summary of evidence

The strongest evidence supports:
- visibility can help
- expertise is essential
- funding is a major constraint
- self-hosting does not automatically create security
- public hosting is not automatically insecure
- There is no one platform That is universally “the secure choice.”
